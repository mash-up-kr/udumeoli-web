## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 카카오 로그인 버튼

- 로그인 성공 시 자동 로그인 유지 (15일 / 30일 중 정책 확정 필요)

### 2. 프로필 생성

- 기본 프로필 이미지 4종 중 선택 가능
- 닉네임 입력 필수 (미입력 시 완료 버튼 비활성화)

### 3. 프로필 사진 이미지

- 카메라 아이콘 클릭 시 앨범 이미지 업로드 가능
- 앨범(갤러리) 첫 진입 시 ‘접근 권한 확인’ 팝업 (3-1) 고지

### 4. 기본 아바타 선택

- 화면 진입 시 4종 중 첫 번째 아바타가 기본 Selected 상태
- 다른 아바타 클릭 시 Selected 상태 이동

### 5. 닉네임 입력 필드

- 닉네임 길이: 최소 1자 ~ 최대 6자 (공백 포함)
- 6자 초과 입력 가능하나(직접 입력·붙여넣기 동일), 초과 시
- "닉네임은 최대 6글자까지 가능해요" 텍스트와 에러 노출 + [완료] 버튼 비활성화
- 공백만 입력한 경우(예: " ") 무효 처리 → 에러 노출
- 중복 닉네임 허용, 특수 기호 사용 가능
- 입력 중 실시간으로 에러 검증

### 6. [완료] 버튼

- 닉네임 6자 이하 조건 충족 시에만 활성화

### 7. 서비스 접근 권한 확인 팝업

- 회원가입 페이지 진입시 바로 등장
- [취소] 클릭 시 → 7-1 필수 권한 허용 권장 팝업 노출

### 7-1. 접근 권한 비허용시 팝업

- 필수 권한(앨범 등) 미허용 상태에서 재진입 시 노출
- [지금 설정] 클릭 시 → 기기 내 설정 앱으로 이동
- [취소 아이콘] 클릭 시 → 팝업 닫기

### 8. 회원가입 완료

- [확인] 클릭 시 → 설명 온보딩 페이지로 이동

### 9. 온보딩

- CTA 누르면 다음 페이지로 이동
- 스와이프 해도 다음 페이지로 이동
