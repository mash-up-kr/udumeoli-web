## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. Recap 버튼

- 클릭 시 → 이미지 추출 화면으로 이동

### 2. 뒤로가기 버튼

- 클릭 시 → 이전 화면으로 복귀 (홈)

### 3. 여행팟 설명 툴팁

- 팟 이름 하단에 노출되는 보조 설명 요소
- “{국가명}에서 {총 여행 지역 수}개의 핀을 만들었어요”

### 4. 리캡 이미지 미리보기

- 화면 중앙에 노출되는 이미지 영역 → 실제로 저장/공유될 이미지의 미리보기 (하단 리캡 내부 디자인 참고)

### 5. 이미지로 내보내기 버튼

- 클릭 시 → 현재 미리보기 이미지를 기기에 저장 시도
- 사진 접근 권한 없을 시, 접근 권한 비허용 팝업 노출

### 6. 토스트) 이미지 저장 성공

- 이미지 저장 성공 시 노출 (3초)

### 6-1. 토스트) 이미지 저장 실패

- 이미지 저장 실패 시(권한 거부, 저장 공간 부족 등) 노출 (3초)
