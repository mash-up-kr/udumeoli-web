## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 상단 툴팁 & 프로필

- 여행 국가와 핀 개수를 요약해서 보여주는 툴팁
- 텍스트: “{국가명}에서 {총 여행 지역 수}개의 핀을 만들었어요”
- 국가명 = MVP 기준 “대한민국”
- N(핀 개수) = 팟이 꽂은 핀(장소) 총 개수
- 프로필 노출 순서 = ‘나'→방장→ 팟 참여 순서대로 (가장 나중에 들어온 사람이 맨 끝)

### 2. 리캡 카드 (메인 공유 이미지)

- 여행 통계 + 지도를 담은 이미지 내보내기용 카드
- 상단 타이틀: 툴팁(위 항목)과 동일한 텍스트, 디자인만 다르게 적용 (예: "10 PINNNED / in KOREA 🇰🇷“)
- 지도: 현재 팟 홈 화면 지도와 동일한 소스 사용, 카드 비율에 맞게 크기만 조정
- 핀 색상/키워드 이모지 매핑: 홈 화면 로직 그대로 유지

### 2-1. 리캡 카드 – 팟 닉네임 라벨

- 카드 좌측에 팟원 닉네임을 태그 형태로 노출
- 같은 팟 소속 멤버 닉네임 전부 노출 (최대 6명, 인원 제한 없이 전부 표시)
- 노출 순서: '나' 최상단 고정 → 이후 방장 → 팟 참여 순서대로 (가장 나중에 들어온 사람이 맨 끝)

### 3. [이미지로 내보내기] 버튼

- 리캡 카드를 이미지로 저장하는 버튼
- 클릭 시 시스템 공유 바텀시트(OS 기본 Share Sheet) 노출
- 사용자가 카메라 롤에 저장 가능

### 4. 스토리용 이미지

- 스토리용 비율임
- 해당 비율로 다운로드 되어야함
- 하단 텍스트
- 상단 : 팟 네임
- 하단 : 팟원 닉네임 라벨 (규칙은 2-1과 동일)

### 5. NEW 규칙

- 여행지 ‘1-5개 등록’ → ‘도 별로’ 노출
- 기존에 사용한 ‘도'별 디자인 그대로 사용하시면 됩니다!
- 6개 이상 → 시 별로 노출 (기존대로)
