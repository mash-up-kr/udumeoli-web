## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. ‘뒤로가기' 버튼

- 이전 화면으로 복귀

### 2. 초대코드 입력 필드 (6칸)

- 영문+숫자 혼용 6자리 고정 입력

### 3. ‘참여하기’ 버튼

- 초대코드 6자리 모두 입력 시 활성화
- 버튼 클릭 시 유효성 검사
- → 에러 케이스 발견 시, 비활성화 (Disabled)

### 4. 토스트) 에러: 존재하지 않는 코드

- 발급된 적 없는 코드 입력 시 노출.
- ■ 토스트 노출 시간 - 3초 노출 후 자동 사라짐 ■

### 5. 토스트) 에러: 현재 참여 중인 여행팟

- 이미 참여 중인 팟의 코드를 재입력했을 때 노출
- ■ 토스트 노출 시간 - 3초 노출 후 자동 사라짐 ■

### 6. 토스트) 에러: 정원이 다 찬 여행팟

- 코드는 유효하나 인원이 6/6으로 꽉 찬 경우 노출, 참여 불가 처리
- ■ 토스트 노출 시간 - 3초 노출 후 자동 사라짐 ■

### 7. 여행팟 정보 확인 그래픽

- 코드 유효 + [참여하기] 탭 시 노출되는 컨펌 단계
- 초대코드 입력 완료 후, 참여할 여행팟 정보(팟 이름, 참여 인원 수, 참여자 닉네임 리스트) 확인 팝업 노출
- 여행팟 최대 인원: 6명 고정, "n/6명 참여 중"으로 카운터 표시
- 팟명, 현재 인원(n/6), 참여 멤버 리스트 노출 → 잘못된 코드로 오인 참여하는 것 방지

### 8. ‘다시 입력' 버튼

- 모달 닫고 코드 입력 화면으로 복귀
- 입력값 초기화

### 9. ‘맞아요' 버튼

- 참여 확정, "여행 지도" 진입 화면으로 이동

### 10. 토스트) 여행팟 참여 완료

- 참여 확정 직후 팟의 "여행 지도" 진입 화면 위에 "OOO에 참여했어요 (n/6)" 토스트로 노출
- ■ 토스트 노출 시간 - 3초 노출 후 자동 사라짐 ■
