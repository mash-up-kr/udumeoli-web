## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. ‘뒤로가기’ 버튼

- 이전 화면으로 복귀

### 2. 여행팟 이름 입력 필드

- placeholder: "우리 팟의 이름을 입력해 주세요."
- 최대 글자수 제한 별도 정의 X
- 최대 글자수 제한 없음, 공백 포함 가능 (개발단에서 임의 지정 가능)
- 중복 이름 허용, 특수기호 사용 가능

### 3. [팟 만들기] 버튼

- 여행팟 이름 1자 이상 입력 시 활성화 (공백도 가능)
- 미입력 시 비활성(Disabled) 유지

### 4. 닫기(X) 버튼

- 클릭 시 "여행팟 내 여행 지도" 화면으로 이동 (신규 생성된 팟의 첫 진입 화면)

### 5. 현재 새로 만든 여행팟 이름

- 새로 만든 여행팟 이름 노출

### 6. 여행팟 티켓

- 여행팟 이름, 여행팟 진입 순서(팟 생성자는 고유 1번), 팟장 닉네임, 팟 생성 당일 날짜, 팟 초대코드 노출
- 인터랙션 삽입 필요 (gif 확인)

### 7. 최대 인원 정보 툴팁

- 첫 생성 후 해당 페이지에서 툴팁 상시 노출 (자동 사라짐 없음)
- 현재 참여 인원/최대 인원(1/6) 실시간 반영

### 8. [초대코드 공유하기] 버튼

- 클릭 시 시스템 공유 바텀시트 노출

### 9. 시작하기 버튼

- 클릭 시 안내 문구(STEP 1/2) 사라지고 지도 화면 노출
- 지도 노출과 동시에 서울 중심으로 줌인 (전국 → 서울)
- 이후 재진입 시에는 안내 문구·시작하기 버튼 없이 바로 지도 노출

### 10. 참여 확인 토스트

- 초대코드로 참여 확정 직후, 빈 지도 화면 하단에 "OOO에 참여했어요 (n/6)" 노출
- OOO = 참여한 팟 이름, n = 현재 참여 인원
- ■ 토스트 노출 시간 - 3초 노출 후 자동 사라짐 ■
