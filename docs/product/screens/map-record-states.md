## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 핀 (1~2단계)

- 노출 조건: 1명 이상이 등록했을 때
- 지역이름 기록하기 버튼 툴팁도 선택적으로 같이 노출
- 줌인 노출 기준 정리 1~2번 참고

### 2. [{지역이름} 기록하기] 버튼 툴팁

- 노출 조건: 팟원 중 누군가 등록한 여행지가 있을 때 (나는 미등록)
- 가장 최근에 등록된 미완료 지역 1곳에만 노출 — 나머지 미완료 지역은 툴팁 없이 지역 표시만
- 예: 남들이 등록한 지역 4곳에 내가 아직 등록하지 않았으면, 가장 최근 등록된 곳에만 "기록하기" 툴팁이 붙고 나머지 3곳은 그냥 핀만 보임
- 클릭 시 → 5번과 동일

### 3. 아무도 업로드하지 않은 지역

- - 버튼 노출,
- 제일 끝까지 줌인된 곳에서 지역 클릭 시 업로드 페이지로 이동

### 4. 내가 업로드한 지역

- 클릭 시 → 4번 바텀시트 노출
- 줌인 기준 정리 3번 참고

### 4-1. 4번 바텀시트

- 키워드는 많이 선택한 순서대로, 동일한 개수면 ㄱㄴㄷ순으로 정렬

### 5. 팟원은 업로드했지만 내가 아직 업로드 안 한 지역

- 클릭 시 → 5번 바텀시트 노출

### 5-1. 5번 바텀시트

- 키워드는 4번과 동일
- 내가 안 올렸기 때문에 "내 사진 올리기" 버튼이 있음
- - 버튼 클릭 시 → 업로드 페이지로 이동

### 6. 인원별 바텀시트 노출 UI

- 참고용 (1인팟 / 2인팟 / 3,4인팟 / 5,6인팟 스크롤 다운 시 슬롯 개수가 달라지는 예시)
