## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 드롭다운

- 지도 뷰의 드롭다운과 기능 및 디자인 동일
- 팟 전환 시 → 하단 카드 리스트 전체가 선택한 팟 기준으로 갱신

### 2. 여행 지역 카드

- 방문한 지역별로 1장씩 생성 (창원/강릉/대전)
- 구성: 지역명 + 기록 인원수 카운트 "N/N명" + 이미지 모음 + Alert (선택)
- 클릭 시 → 해당 지역 상세 페이지로 이동

### 3. 특정 여행 지역 내 미기록 시 Alert 문구

- 노출 조건: 이 지역의 과거 방문 건 중 내가 업로드하지 않은 여행이 하나라도 남아있을 때
- 문구: "아직 기록하지 않은 여행이 있어요"

### 4. 기록 인원수 카운트

- 팟 멤버 수 중 사진을 올린 인원 수를 표시
- 예: 팟 멤버 4명 중 3명이 올렸으면 "3/4명"

### 5. 여행 이미지 규칙

- 이미지 개수 = 팟 멤버 수
- 6개, 5명이면 5개, 4명→4개, 3명→3개, 2명→2개, 1명→1개
- 이미지 순서 = 좌측부터 팟에 들어온 순서(가입 순)로 고정 배정.
- 올린 사람: 사진만 노출 (이름/닉네임 뱃지 없음)
- 안 올린 사람: Zzz 아이콘으로 표시, 점선으로 표현
- 사람을 구분하는 별도 뱃지·아바타 요소는 없음 (이미지 자체가 그 사람의 고정 자리라서, 위치만으로 "누구 자리인지"를 나타냄)

### 6. GNB - 지구본

- 클릭 시 → 지도 뷰로 이동

### 7. GNB - 마이페이지

- 클릭 시 → 마이페이지 메인 뷰로 이동
