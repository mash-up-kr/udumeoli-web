## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 참여 중인 팟 = 0개일 때

- 메인 진입 시 전용 온보딩 화면 노출. 아직 어떤 팟에도 속하지 않은 최초 상태에서만 나타남.

### 2. ‘뒤로가기’ 버튼

- 클릭 시 이전 페이지(온보딩 페이지)로 이동

### 3. 새 팟 만들기

- 클릭 시 → 여행팟 생성 화면으로 이동

### 4. 초대코드로 참여하기

- 여행팟 참여 화면으로 이동

### 5. [드롭다운] 각 여행팟 리스트

- 메인 홈 상단 여행팟명 클릭 시 드롭다운 오픈 → 다른 여행팟으로 이동 가능
- 현재 내가 참여 중인 여행팟 목록 노출, 클릭 시 해당 팟으로 이동
- 여행팟 이름은 글자수 제한 없이 노출하되, 2줄 초과 시 말줄임(...) 처리 예) "민지 ❤️ 성준 영원히 함께하자 안녕하세요 민지 성준입..."
- 현재 보고 있는 팟은 체크 아이콘으로 표시
