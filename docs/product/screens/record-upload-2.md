## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 7. 사진 코멘트

- placeholder: "사진 한 줄 설명을 적고 친구와 공유해요"
- 선택 입력

### 8. [확인] 버튼

- 클릭 시 → 다음 화면(9~14번, 선택완료/업로드완료 화면)으로 이동
- 활성화 조건: 코멘트 입력 없이 사진만 올려도 버튼 활성화 (코멘트는 선택 입력, 필수 아님)

### 9. 지역명 뱃지 (키워드 색상 버전)

- 선택한 키워드별로 지정된 색상을 뱃지 배경(bg)에 대응해서 노출

### 10. OOO!투어 키워드 노출

- 키워드명("디저트!투어") 텍스트에 밑줄 + 9번과 같은 키워드 컬러(레드) 적용
- 인터랙션: 진입 시 옆의 이모지가 "빵!" 터지는 연출

### 11. 프로필/닉네임

- 업로드한 사람의 프로필 이미지 + 닉네임 노출

### 12. 업로드한 이미지

- 이전 페이지에서 업로드한 이미지 노출

### 13. 사진 코멘트 노출

- 사진 아래, 말풍선(포인터가 사진 쪽을 향함) 형태
- 키워드 스티커 아이콘 + 코멘트 텍스트 함께 노출

### 14. 지도에 기록하기 버튼

- 클릭 시 → 실제 지도에 반영되며 15번 완료 토스트 노출

### 15. 기록 완료 토스트

- 노출 조건: 사진 업로드 및 지도 기록 완료 직후
- 문구: '지역' 여행 Pinned 완료!
