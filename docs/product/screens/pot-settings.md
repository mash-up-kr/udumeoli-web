## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 팟 이름 수정 [저장] 버튼

- 팟 이름에 변동사항이 하나라도 생기면 버튼 노출
- 저장 버튼 클릭 시 → 변경된 이름으로 저장
- 팟 이름 규칙은 → 기존에 온보딩에서 작성한 규칙과 동일

### 2. 멤버 표시

- 본인은 (ME) 표시
- 팟장/팟원 뱃지 구분 표시
- 정렬 순서: 나(본인) 최상단 고정 → 이후 팟원은 가입 순서대로 (예: 민준이가 팟장 다음으로 가장 먼저 들어왔으면 그 다음 순번)

### 3. 초대코드 복사 아이콘

- 클릭 시 초대코드 클립보드 복사
- 복사 후 "초대코드가 복사됐어요"토스트 노출

### 4. 초대 링크 공유하기 버튼

- 클릭 시 초대 링크가 클립보드에 복사된 상태로 시스템 공유 모달(OS 공유 시트) 노출

### 5. 팟 삭제하기 버튼

- 팟장에게만 노출 (팟원에게는 미노출)
- 클릭 시 5-1 삭제 확인 모달 노출

### 5-1. 팝업) 팟 삭제하기

- [취소] 버튼 클릭 시 → 모달 닫힘, 팟 설정 화면 복귀
- [팟 삭제] 버튼 클릭 시 → 팟 및 팟에 속한 모든 데이터 서버에서 영구 삭제 처리
- 초대코드도 함께 즉시 만료 처리

### 6. 팟 나가기 버튼

- 클릭 시 6-1 나가기 확인 모달 노출

### 6-1. 팝업) 팟 나가기

- 실행자 본인만 팟 멤버 목록에서 제외, 나머지 멤버 및 팟 자체 데이터는 유지
- 멤버 수 갱신: "멤버 (n)" → "멤버 (n-1)"으로 실시간 반영
- 실행자 화면: 팟 설정 화면 → 홈/팟 목록 화면으로 자동 이동, 완료 토스트 노출("팟에서 나갔습니다" 등)
- 팟장이 나가는 경우: 남은 멤버 중 가장 먼저 팟에 참여한 인원에게 팟장 자동 위임할
- 나간 후 동일 초대코드/링크로 재입장 가능 (팟원으로)
- [취소] 버튼 클릭 시 → 모달 닫힘, 팟 설정 화면 복귀
- [팟 나가기] 버튼 클릭 시 → 실행자의 팟에 속한 모든 데이터 서버에서 영구 삭제 처리

### 7. 팟원 시점 권한 정리

- 팟 삭제하기 미노출
- 팟 이름 수정 가능
