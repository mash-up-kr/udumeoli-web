## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. ‘뒤로가기' 버튼

- 클릭 시 → 이전 화면으로 복귀

### 2. 지역 헤더

- 지역명 + 팟 멤버 프로필 아이콘 나열 + "n/N명 기록 완료" 카운터
- n = 해당 지역에 사진을 올린 멤버 수, N = 팟 전체 멤버 수
- 프로필 순서: 나(본인) 최상단 고정 → 이후 팟원은 가입 순서대로 (마이페이지와 동일)
- 카운터는 업로드/삭제 시 실시간 반영
- 업로드하지 않은 유저는 점선으로 프로필 표시
- 업로드한 유저는 실선으로 프로필 표시

### 3. 키워드 칩

- 해당 지역에 올라온 사진의 키워드를 종류별로 집계해 칩으로 노출 (예: 디저트 2 · 사진 2)
- 숫자 = 해당 키워드로 등록된 사진 수
- 키워드가 없는 지역(기록 0개)에서는 칩 영역 미노출

### 4. 기록 카드 그리드

- 카드 순서: 나(본인) 최상단 고정 → 이후 팟원은 가입 순서대로
- 팟 인원에 따라 레이아웃 분기
- 1인팟: 1열 풀폭 카드 (case 01)
- 2인팟 이상: 2열 그리드 (case 02, case 03)
- 1인팟에서 본인이 미기록 상태면 해당 UI 접근 불가하기에 별다른 케이스 고려 X

### 4-1. 내 기록 카드 (기록 X)

- 본인이 아직 사진을 안 올린 상태의 CTA 카드
- 프로필 + 닉네임 + ME! 뱃지 + [+ 내 사진 올리기] 노출
- 클릭 시 → 해당 지역의 기록하기(업로드) 플로우로 진입
- 본인이 업로드 완료하면 이 카드는 사라지고 4-3 기록 카드+ ME! 뱃지로 대체

### 4-2. 타인 기록 카드 (기록 X)

- 해당 멤버가 아직 사진을 안 올린 상태의 placeholder 카드
- 프로필 + 닉네임 + zzZ 그래픽만 노출
- 클릭 액션 없음 (본인 카드와 달리 CTA 없음)

### 4-3. 기록 카드 (기록 O)

- 팟 멤버가 올린 사진 1장 + 프로필/닉네임 + 코멘트 + 키워드 스티커(우상단)로 구성
- 코멘트는 최대 2줄 노출, 초과 시 말줄임
- 카드 클릭 시 → 여행 이미지 상세 보기 페이지로 이동

### 4-4. ME! 뱃지

- 본인 카드에만 노출되는 식별 뱃지 (기록 O/X 무관)
