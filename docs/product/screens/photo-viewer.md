## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 나가기 버튼

- 클릭 시 → 이전 화면으로 복귀
- 수정/삭제 드롭다운 열려있는 상태에서 클릭 시 → 드롭다운 먼저 닫힘

### 2. 더보기 버튼

- 클릭 시 → 수정/삭제 드롭다운 노출 (case.01-3)
- 본인이 업로드한 사진에만 노출 (타인 사진에는 버튼 숨김, case 02)
- 팟원 전체 편집 권한 부여 시 → 노출 조건 별도 정책 필요

### 2-1. 수정/삭제 드롭다운

- 수정하기 클릭 시 → 수정 화면(여행 기록)으로 이동
- 삭제하기 클릭 시 → 삭제 확인 팝업 노출
- 삭제 확인 팝업에서 최종 확인 시 → 삭제 처리
- 팝업에서 취소 클릭 시 → 드롭다운 닫고 원래 화면 유지
- 해당 지역/날짜 마지막 1장 삭제 시 → 상위 리스트 화면으로 복귀

### 2-2. 토스트) 수정 완료

- 수정 완료 시 노출 (3초)
- 수정된 내용 즉시 화면에 반영

### 2-3. 팝업)

- 삭제하기 클릭 시 → 노출
- 닫기(X) 클릭 시 → 팝업 닫고 원래 화면 유지
- 취소 클릭 시 → 팝업 닫고 원래 화면 유지
- 삭제 클릭 시 → 삭제 처리, 토스트(2-4) 노출

### 2-4. 토스트) 삭제 완료

- 삭제 완료 시 노출 (3초)
- 삭제 완료 후 → 이전 화면으로 복귀

### 3. 닉네임 뱃지

- 사진 업로더의 프로필 아이콘 + 닉네임 노출
- 본인 사진일 경우 → "ME!" 뱃지 함께 노출

### 4. 스티커/코멘트 툴팁

- 사진 하단에 노출되는 업로더의 키워드 아이콘, 코멘트

### 5. 이미지 전체 화면 (UI 숨김)

- 사진 영역 클릭 시 → 헤더/뱃지/툴팁 숨김, 전체화면 전환
- 전체화면에서 재클릭 시 → 다시 노출
- 좌우 스와이프로 다음/이전 사진 이동 가능 (동일 지역에 한함)

### 6. 다시 시도 버튼

- 이미지 로드 실패 시 노출
- 클릭 시 → 이미지 재요청
- 재요청 성공 시 → 정상 이미지로 교체
