## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 닉네임 수정

- 클릭 시 → 프로필 수정 화면으로 이동

### 2. 내 팟

- 내 팟 리스트
- 리스트 순서 → 가장 최근에 들어온 팟이 최상단에 위치
- ex. 우두머리 (26.8월 입장) / 강민지원 (26.7월 입장) / 21학번모임 (25년 입장)

### 3. 이용 약관

- [이용약관] / [개인정보처리방침] 클릭 시 → 노션 페이지로 연결

### 4. 프로필 수정 화면

- 기존에 유저가 입력했던 닉네임/아바타 정보 그대로 노출된 상태로 진입
- 카메라 아이콘 클릭 시 → 사진 업로드 (온보딩과 동일)
- 닉네임 재입력 규칙은 온보딩과 동일하게 적용

### 4-1. [저장] 버튼 활성화 조건

- 닉네임 또는 아바타 중 하나라도 기존 값과 달라지면 활성화
- 둘 다 기존 값과 동일하면 비활성화 유지
- 이미 선택된 아바타를 재클릭한 경우 변경 없음으로 처리 (버튼 비활성화 유지)
- 닉네임 가능 조건은 회원가입 시와 동일

### 4-2. 저장 처리

- [저장] 버튼 클릭 시 → 저장 후 마이페이지로 이동
- 변경사항이 있는 상태(=저장 버튼 활성화 상태)에서 [저장] 없이 ←(뒤로가기) 클릭 시 → 변경사항 미반영 상태로 마이페이지 이동
- 변경사항이 없는 상태(=저장 버튼 비활성화 상태)에서 ← (뒤로가기) 클릭 시 → 마이페이지로 이동

### 5. 로그아웃 버튼

- [로그아웃] 클릭 시 → 5-1의 로그아웃 확인 팝업 노출

### 5-1. 로그아웃 확인 팝업

- [로그아웃] 클릭 시 → 로그아웃 진행 후 스플래시 화면 이동
- [취소] 클릭 시 → 팝업 닫힘, 마이페이지 화면 유지

### 6. 로그아웃 완료 토스트

- 스플래시 화면 진입 후 "로그아웃이 완료됐어요." 토스트 노출

### 7. 로그아웃 버튼

- [계정 삭제] 클릭 시 → 7-1의 재확인 팝업 노출

### 7-1. 계정 삭제 확인 팝업

- \[계정 삭제\](삭제 확정) 클릭 시 → 계정 삭제 진행 후 스플래시 화면 이동
- [취소] 클릭 시 → 팝업 닫힘, 마이페이지 화면 유지
- ✅ 계정 삭제 시 데이터 처리 정책
- 해당 유저가 업로드한 사진 삭제
- 해당 유저가 속한 모든 여행팟에서 탈퇴 처리되며, 해당 자리는 공석(빈 자리)으로 전환 (여행팟 자체는 유지)

### 8. 계정 삭제 완료 토스트

- 스플래시 화면 진입 후 "계정 삭제가 완료되었습니다. 감사합니다." 토스트 노출
