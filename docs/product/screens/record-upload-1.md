## 기획 내용

원문 항목 번호와 조건·문구를 보존했다. 표현상 중복이나 모순은 임의 수정하지 않았다.

### 1. 뒤로가기 버튼

- 클릭 시 → 이전 화면으로 이동

### 2. 지역명 뱃지

- 그냥 지역명 노출 (기본, 키워드 색상 반영 없음)

### 3. 키워드 칩 리스트

- 맛집 / 디저트 / 힐링 / 액티비티 / 사진 중 1개 선택

### 3-1. 키워드 selected 상태

- 칩 선택 시 강조 표시로 전환 (예: '디저트' 선택 시 진하게)
- 다른 칩 선택 시 선택한 칩으로 전환

### 4. [다음] 버튼

- 키워드 선택 후 활성화

### 5. 선택한 키워드 표시

- 사진 프레임 좌상단에 걸쳐있는 알약형 칩
- 아이콘 + 이전 화면에서 선택한 키워드명 노출 — 이전 화면 선택값이 그대로 넘어옴

### 6. [사진 추가하기] 버튼

- 큰 사각 플레이스홀더 영역 중앙에 위치
- "+" 아이콘 + "사진 추가하기" 텍스트
- 클릭 시 → 6-1(갤러리) 화면으로 이동

### 6-1. 갤러리(OS 사진 라이브러리) 화면

- 사용자가 여기서 사진 1장을 고르면 → 6번 화면으로 복귀해 대표 사진 자리에 반영됨
