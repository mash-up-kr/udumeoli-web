# 미확정 사항과 충돌

확인일: 2026-10-20. 아래는 미확정 원문, 문서 충돌, 누락된 정의를 구분한 목록이다. 질문과 제안은 확정 기획이 아니다. 초기 상태는 모두 **열림 / 사용자 결정 대기**다. 기획에 없는 세부값을 모두 새 요구사항으로 추가하지 말고, 실제 작업에 필요한 항목만 질문한다.

결정 시 해당 항목의 상태를 `해결`로 바꾸고 결정 내용·사용자 근거(대화 날짜와 요지)·영향 문서·결정일을 기록한다. 기존 질문과 근거는 삭제하지 않는다. 현재 열린 항목 중 개발에 영향을 주는 것은 결과 보고에도 명시한다.
